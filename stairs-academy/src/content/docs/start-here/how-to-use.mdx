The curriculum is organized into five chapters. You can go through them in order or jump to any topic.

## Lesson Structure

Each page follows the same layout:

| Section          | What It Is                                                                 |
| ---------------- | -------------------------------------------------------------------------- |
| **The Big Idea** | One-paragraph summary. If you read nothing else, read this.                |
| **See It**       | An animated video (30–90 seconds) showing the concept visually.            |
| **Play With It** | An interactive simulation. Move sliders, toggle options, see what happens. |
| **The Details**  | Diagrams, callouts, and explanations of key terms.                         |
| **In STAIRS**    | How this concept maps to the STAIRS application's logic or settings.       |
| **Deep Dive**    | Collapsible section with equations and physics for those who want them.    |

## Tips

- **Interact with the simulations.** Click around, drag sliders, try extreme values. Breaking things is the best way to learn.
- **Watch the animations more than once.** Concepts like field rotation and stacking take a moment to click.
- **The Deep Dives are optional.** You don't need to understand the math to use STAIRS effectively. They're there for curiosity.
- **Use the sidebar.** Each chapter has 4–5 pages. The sidebar shows where you are.

## Prerequisites

- Basic familiarity with your smart telescope's app (you've taken a picture before)
- That's it. No math, no physics degree required.

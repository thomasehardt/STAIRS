Bayer Filter

Each pixel in a digital camera sensor is colorblind — it only measures intensity. A Bayer filter array places red, green, and blue filters over individual pixels so each one captures only one color channel. The Scene panel shows the true image, Bayer Raw shows what each pixel captures (only its filter's channel), and Debayered shows the reconstructed image after demosaicing. In Single mode photons land one at a time; in Parallel mode all pixels accumulate simultaneously.
